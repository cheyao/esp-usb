# ESP USB

![](https://hc-cdn.hel1.your-objectstorage.com/s/v3/581c97c7904b929b346521dac1195fcf45c66e19_image.png)

The tiny ESP32 development board that you can plug directly into your USB port.

This board is tiny enabling small projects. Has 8 GPIO pins, allowing diverse applications.

It is routed only using 2 layers, thus lowering the cost.

It is also portable - no external devices (except your laptop) are needed in order to program the chip!

![](https://hc-cdn.hel1.your-objectstorage.com/s/v3/0a95e10848faf162e861499aae798dcaf59fbabb_image.png)

Features:
- Tiny
- Portable
- Reliable
- Onboard USB receptor
- 8 GPIOs

![](https://hc-cdn.hel1.your-objectstorage.com/s/v3/d94dfb82993dd991c6b07bc3e5494b0e028188f9_image.png)

If you need to supply 5v, solder a wire onto the usb pad.
